# 꿈별이의 룸메이트 찾기

간단한 횡스크롤 미니게임 프로토타입입니다.

## 게임 방식
- 기본 꿈별이만 이동합니다.
- 깔끔한/조용한/활발한 룸메이트 꿈별이는 자기 자리에서 대기합니다.
- 꿈별이가 만나면 유형 팝업이 열립니다.
- 세 명을 모두 만나면 마지막 선택 화면이 나옵니다.
- PC: ← → 이동, Space 점프
- 모바일: 하단 버튼

## GitHub Pages
1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 파일과 `images` 폴더를 그대로 업로드합니다.
3. Settings → Pages → Deploy from a branch → `main` / `/root` 선택
4. 생성된 Pages 주소로 접속합니다.
